%(BEGIN_ANSWER)

Superskriptet 20/4 betyr at eddiksyren er så mye tettere ved 20$^{o}$ C enn vann er ved 4$^{o}$ C.

%(END_ANSWER)





%(BEGIN_NOTES)

Først beregnes hydrostatisk trykk som om kolonnen var vann i stedet for eddiksyre:

\vskip 10pt

(12.3 m)(100 cm / 1 m)(1 inch / 2.54 cm)(1 PSI / 27.6807 "W.C.) = 17.494 PSI

\vskip 10pt

Deretter korrigeres for eddiksyres spesifikke vekt på 1.0492:

\vskip 10pt

(17.494 PSI)(1.0492 "W.C. / "acid) = 18.355 PSI

\vskip 10pt
