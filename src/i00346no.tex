Faste stoffer utvider seg vanligvis når de varmes opp. Hvor mye et fast stoff utvider seg ved temperaturøkning, avhenger av størrelsen på prøven og materialet den er laget av. En formel for lineær utvidelse som funksjon av temperatur er:

$$l = l_0 (1 + \alpha \Delta T)$$

\noindent
Der,

$l$ = materialets lengde etter oppvarming

$l_0$ = materialets opprinnelige lengde

$\alpha$ = koeffisient for lineær utvidelse

$\Delta T$ = temperaturendring

\vskip 10pt

Her er noen typiske verdier for $\alpha$ for vanlige metaller:

\begin{itemize}
\item{} Aluminium = 25 $\times$ $10^{-6}$ per grad C
\item{} Kobber = 16.6 $\times$ $10^{-6}$ per grad C
\item{} Jern = 12 $\times$ $10^{-6}$ per grad C
\item{} Tinn = 20 $\times$ $10^{-6}$ per grad C
\item{} Titan = 8.5 $\times$ $10^{-6}$ per grad C
\end{itemize}

Vi kan også uttrykke hvordan \textit{arealet} og \textit{volumet} til et fast stoff øker ved oppvarming, ikke bare lineære mål. Hvis vi ser for oss et kvadrat med opprinnelig lengde $l_0$ og opprinnelig bredde $l_0$, må opprinnelig areal være ${l_0}^2$, og nytt areal etter oppvarming blir:

$$A = [l_0 (1 + \alpha \Delta T)]^2$$

$$A = l_0^2 (1 + \alpha \Delta T)^2$$

$$A = l_0^2 (1 + \alpha \Delta T)(1 + \alpha \Delta T)$$

$$A = l_0^2 [1 + 2 \alpha \Delta T + (\alpha \Delta T)^2]$$

$$\hbox{eller}$$

$$A = A_0 [1 + 2 \alpha \Delta T + (\alpha \Delta T)^2]$$

\vskip 10pt

Likningen kan forenkles ved approksimasjon, et matematisk prinsipp som ofte brukes i elektroteknikk og kalles \textit{swamping}:

$$A \approx A_0 (1 + 2 \alpha \Delta T)$$

Forklar hvorfor denne forenklingen er akseptabel, og utled tilsvarende prinsipp for å beregne nytt \textit{volum} av et fast materiale etter oppvarming.

Merk at koeffisienten for volumetrisk utvidelse er omtrent tre ganger koeffisienten for lineær utvidelse, slik koeffisienten for arealutvidelse var omtrent to ganger koeffisienten for lineær utvidelse. Dette er nyttig: kjenner vi én av koeffisientene, kan vi anslå alle tre.

Merk også at denne tilnærmingen bare gjelder materialer som er \textit{isotrope}: de utvider seg med samme forhold i alle retninger ved oppvarming.
