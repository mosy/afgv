I første eksempel er relevant omgivelsestemperatur 76 $^{o}$F, fordi referansekompensasjonstermistoren står der. For type K ved denne temperaturen er referanseskjøtspenningen 0.978 mV. Denne må trekkes fra ønsket temperaturspenning før potensiometeret settes:

\begin{itemize}
\item{} {\bf Type K}
\item{} 0$^{o}$ F ; potensiometerinnstilling = $-$0.692 mV $-$ 0.978 mV = {\bf $-$1.670 mV}
\item{} 300$^{o}$ F ; potensiometerinnstilling = 6.094 mV $-$ 0.978 mV = {\bf 5.116 mV}
\item{} 600$^{o}$ F ; potensiometerinnstilling = 12.855 mV $-$ 0.978 mV = {\bf 11.877 mV}
\end{itemize}

\vskip 10pt

I andre eksempel er relevant omgivelsestemperatur 68 $^{o}$F, fordi referansekompensasjonstermistoren står der. For type J ved denne temperaturen er referanseskjøtspenningen 1.019 mV. Denne trekkes fra ønsket temperaturspenning:

\begin{itemize}
\item{} {\bf Type J}
\item{} 400$^{o}$ F ; potensiometerinnstilling = 11.025 mV $-$ 1.019 mV = {\bf 10.006 mV}
\item{} 600$^{o}$ F ; potensiometerinnstilling = 17.188 mV $-$ 1.019 mV = {\bf 16.169 mV}
\item{} 800$^{o}$ F ; potensiometerinnstilling = 23.320 mV $-$ 1.019 mV = {\bf 22.301 mV}
\end{itemize}

\vskip 10pt

I tredje eksempel er relevant omgivelsestemperatur 50 $^{o}$F, fordi det er der den additive termoelementskjøten ligger. En subtraktiv referanseskjøt finnes ved måleinstrumentet, men denne kanselleres av kompensasjonstermistorbroen og er derfor uten betydning her. En reell termoelementskjøt ved presisjonspotensiometeret gjør i praksis det samme som et kompensasjonsnettverk når det ikke finnes referanseskjøt å kompensere: den legger til en uønsket spenning på instrumentinngangen. For type J ved 50 $^{o}$F er denne spenningen 0.507 mV. Den må derfor trekkes fra ønsket temperaturspenning:

\begin{itemize}
\item{} {\bf Type J}
\item{} 250$^{o}$ F ; potensiometerinnstilling = 6.421 mV $-$ 0.507 mV = {\bf 5.914 mV}
\item{} 500$^{o}$ F ; potensiometerinnstilling = 14.110 mV $-$ 0.507 mV = {\bf 13.603 mV}
\item{} 750$^{o}$ F ; potensiometerinnstilling = 21.787 mV $-$ 0.507 mV = {\bf 21.280 mV}
\end{itemize}
