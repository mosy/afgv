Rekkefølge for maksimal driftstemperatur fra lavest til høyest er: (S og R), K, E, J og T.

\vskip 10pt

Felles trekk: negativ leder er alltid {\it rød}, og kappe for termoelementkvalitet er alltid {\it brun}. Positiv lederfarge samsvarer ofte (men ikke alltid) med kappefargen for forlengelseskvalitet.

Noen huskeregler:

\vskip 10pt

{\bf Type J} har {\it jet}-svart forlengelseskappe. Likevel er positiv leder hvit, ikke svart.

\vskip 10pt

{\bf Type K} har {\it kanari}-gul forlengelseskappe. Positiv leder er også gul.

\vskip 10pt

{\bf Type E} har fiolett forlengelseskappe (og positiv leder), omtrent slik lilla var ``kongelig'' i {\it europeiske} monarkier. Bokstaven E minner også om ``electrical'', og type E har høy mV/grad-følsomhet.

\vskip 10pt

{\bf Type T} brukes ofte ved lave {\it temperaturer}, og har ``iskald'' {\it blå} kappe og positiv leder.

\vskip 10pt

{\bf Type S}: Bokstaven ``S'' kan assosieres med dollartegn (\$). Denne typen er av platina og derfor {\it kostbar}. Forlengelseskappen er grønn, som penger. Som type J matcher ikke positiv leder kappen her heller: positiv leder er svart.

\vskip 10pt

{\bf Type R} er nesten identisk med type S i fargekoder. Siden R kommer ``lavere'' enn S i alfabetet, kan man tenke på type R som ``ett trinn under'' type S. Positiv legering har mindre platina og mer rhodium enn type S.
