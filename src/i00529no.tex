Ultralyd strømningsmålere har særlige fordeler og ulemper sammenlignet med andre strømningsmåleteknologier. For hver av følgende styrker og svakheter, forklar \textit{hvorfor} dette gjelder for en ultralyd strømningsmåler:

\vskip 10pt

{\bf Styrker:}

\begin{itemize}
\item{} Kan monteres på \textit{utsiden} av et rør
\item{} Relativt rimelig på store rør
\item{} Fungerer på væsker, gasser og noen damper
\item{} Utgangen er lineært relatert til volumstrøm -- ingen kvadratrotekstraksjon nødvendig
\item{} God reguleringsbredde
\item{} Toveis måling er mulig
\end{itemize}

\vskip 10pt

{\bf Svakheter:}

\begin{itemize}
\item{} Kalibrering varierer med lydhastighet i væsken for noen typer (hvilke?)
\item{} Effektiv kobling av sensorer til røret kan være utfordrende
\item{} Kan kreve lange rette rørlengder for å kondisjonere strømningen
\item{} Kan få falske avlesninger når lydbølger ``ringer rundt røret'' i stedet for å gå gjennom væsken
\end{itemize}

{\bf Styrker:}

\begin{itemize}
\item{} Kan monteres på \textit{utsiden} av et rør -- \textit{man trenger bare å lede lydbølger gjennom væsken for å måle hastigheten}
\item{} Relativt rimelig på store rør -- \textit{transduserstørrelsen skalerer ikke med rørstørrelsen, så små transdusere kan brukes på svært store rør}
\item{} Fungerer på væsker, gasser og noen damper -- \textit{alle medier som kan overføre lyd, kan i prinsippet måles}
\item{} Utgangen er lineært relatert til volumstrøm -- ingen kvadratrotekstraksjon nødvendig -- \textit{Doppler-frekvensforskyvning er lineær med hastighet; det samme gjelder transit-time-differansen}
\item{} God reguleringsbredde -- \textit{lineær respons gir god turndown}
\item{} Toveis måling er mulig -- \textit{Doppler-forskyvningen skifter bare fortegn med retning; det samme gjelder transit-time-forskjeller}
\end{itemize}

\vskip 10pt

{\bf Svakheter:}

\begin{itemize}
\item{} Kalibrering varierer med lydhastighet i væsken for noen typer (hvilke?) -- \textit{Doppler avhenger av $c$; transit-time gjør ikke det}
\item{} Effektiv kobling av sensorer til røret kan være utfordrende -- \textit{man trenger god akustisk kobling for å sikre signalkvalitet}
\item{} Kan kreve lange rette rørlengder for å kondisjonere strømningen -- \textit{fordi én lydbane bare fanger hastighet langs ett spor, og virvler/rotasjon kan redusere nøyaktighet}
\item{} Kan få falske avlesninger når lydbølger ``ringer rundt røret'' i stedet for å gå gjennom væsken -- \textit{lydbølger kan forplante seg i rørveggen i stedet for gjennom væsken, særlig ved clamp-on-målere}
\end{itemize}
