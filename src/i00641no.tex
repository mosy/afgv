\vskip 10pt

Hvilken type termoelement har ledere farget {\it blå} og {\it rød}? Type {\bf T}

Hvilken termoelementtype egner seg best for høyere temperaturer, type E eller type S? Type {\bf S}

\vskip 10pt

Hvilken farge får ytterkappen på en type E termoelementkabel? {\bf Brun}

\vskip 10pt

Hvilken farge får ytterkappen på en type SX forlengelseskabel? {\bf Grønn}
