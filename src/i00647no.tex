$$PV = nRT \hbox{ \hskip 30pt (Ideell gasslov)}$$

\noindent
Der,

$P$ = Absolutt trykk (atmosfærer)

$V$ = Volum (liter)

$n$ = Gassmengde (mol)

$R$ = Universell gasskonstant (0.0821 L $\cdot$ atm / mol $\cdot$ K)

$T$ = Absolutt temperatur (K)

\vskip 50pt

$${dQ \over dt} = {{A \Delta T} \over R} \hskip 50pt {dQ \over dt} = {{k A \Delta T} \over l} \hskip 50pt {dQ \over dt} = e \sigma A T^4$$

\noindent
Der,

$dQ \over dt$ = Varmeoverføringsrate

$e$ = Emissivitetsfaktor

$\sigma$ = Stefan-Boltzmann-konstanten (5.67 $\times$ $10^{-8}$ W / m$^{2}$ $\cdot$ K$^{4}$)

$A$ = Overflateareal

$T$ = Absolutt temperatur

$\Delta T$ = Temperaturforskjell

$R$ = ``R''-verdi for isolasjon (enheter ft$^{2} \cdot$h$\cdot ^{o}$F / BTU)

$k$ = Varmeledningsevne

$l$ = Lengde på varmeflytbanen

\vskip 50pt

$$R_T = R_{ref} \left[1 + \alpha (T - T_{ref}) \right]$$

\vskip 10pt

$$Q = mc \Delta T \hskip 50 pt Q = mL$$
