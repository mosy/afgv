En differansetrykk-flowmåler (f.eks. orifiseplate, venturi osv.) har kalibrert flowområde 0 til 1000 GPM og differansetrykkområde 0 til 200 inches vannsøyle.

\vskip 10pt

Beregn nytt differansetrykkområde for transmitteren for å gi nytt flowområde 0 til 750 GPM.

\vskip 10pt

Beregn nytt differansetrykkområde for transmitteren for å gi nytt flowområde 0 til 1200 GPM.

\vskip 10pt

Beregn nytt differansetrykkområde for transmitteren for å gi nytt flowområde 0 til 510 GPM, og oppgi dette i PSI i stedet for inches vannsøyle.

\underbar{file i00692no}
%(END_QUESTION)





%(BEGIN_ANSWER)

Nytt $\Delta$P-område = 0 til 112.5 inches vannsøyle for $Q$ = 0 til 750 GPM

\vskip 10pt

Nytt $\Delta$P-område = 0 til 288 inches vannsøyle for $Q$ = 0 til 1200 GPM

\vskip 10pt

Nytt $\Delta$P-område = 0 til 1.879 PSI for $Q$ = 0 til 510 GPM

%(END_ANSWER)





%(BEGIN_NOTES)

$$Q = 70.71 \sqrt{\Delta P}$$
