Bernoullis ligning uttrykt med massetetthet ($\rho$) og vektetthet ($\gamma$):

$$z_1 \rho g + {v_1^2 \rho \over 2} + P_1 = z_2 \rho g + {v_2^2 \rho \over 2} + P_2$$

$$z_1 + {v_1^2 \over {2 g}} + {P_1 \over \gamma} = z_2 + {v_2^2 \over {2 g}} + {P_2 \over \gamma}$$

\noindent
Der,

$z$ = Fluidhøyde i fot (ft)

$\rho$ = Massetetthet i slug per kubikkfot (slug/ft$^{3}$)

$\gamma$ = Vektetthet ($\gamma = \rho g$) i pund per kubikkfot (lb/ft$^{3}$)

$g$ = Tyngdeakselerasjon i fot per sekund kvadrert (ft/s$^{2}$)

$v$ = Fluidhastighet i fot per sekund (ft/s)

$P$ = Fluidtrykk i pund per kvadratfot (lb/ft$^{2}$)

\vskip 10pt
\hrule
\vskip 10pt

Volumetrisk strømning:

$$Q = A \overline{v}$$

\noindent
Der,

$Q$ = Volumetrisk strømning i kubikkfot per sekund (ft$^{3}$/s)

$A$ = Tverrsnittsareal i kvadratfot (ft$^{2}$)

$\overline{v}$ = Gjennomsnittlig strømningshastighet i fot per sekund (ft/s)
\vskip 10pt
\hrule
\vskip 10pt

Beregning av Reynolds-tall:

$$\hbox{Re} = {{(3160) G_f Q} \over {D \mu}}$$

\noindent
Der,

Re = Reynolds-tall (enhetsløs)

$G_f$ = Spesifikk vekt av væsken (enhetsløs)

$Q$ = Strømningsrate i gallons per minute (GPM)

$D$ = Rørdiameter i inches (in)

$\mu$ = Absolutt viskositet i centipoise (cP)
