Beregn reset-tiden til denne I-regulatoren (integral-only), utgangssignalet under følgende betingelser, samt regulatorens virkningsretning:

$$\includegraphics[width=15.5cm]{i00809x01.eps}$$

Reset-tid = \underbar{\hskip 50pt} minutter per repetisjon

\vskip 10pt

\noindent
Anta:

\begin{itemize}
\item{} SP-signal = 3 volt (konstant)
\item{} PV-signal = 2.4 volt (konstant)
\item{} Utgangssignal (ved tid = 0) = 3.4 volt
\end{itemize}

\vskip 10pt

Utgangssignal (ved tid = 3.3 minutter) = \underbar{\hskip 50pt} volt

\vskip 10pt

{\it Direkte} eller {\it revers} virkning?

\underbar{file i00809}
%(END_QUESTION)





%(BEGIN_ANSWER)

Jeg anbefaler 3 poeng for korrekt reset-tid, 4 poeng for korrekt beregning av utgangssignal og 3 poeng for riktig virkningsretning:

\vskip 10pt

Reset-tid = \underbar{\bf 1.485} minutter per repetisjon

\vskip 10pt

Utgangssignal (ved tid = 3.3 minutter) = \underbar{\bf 4.733} volt

\vskip 10pt

{\bf Revers} virkning

%(END_ANSWER)
