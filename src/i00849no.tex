Først beregnes linjestrømmens beløp (forutsatt balansert trefasemotor):

$$P = I_{line} V_{line} \sqrt{3}$$

$$I_{line} = {P \over V_{line} \sqrt{3}}$$

$$I_{line} = {95000 \hbox{ W} \over (480 \hbox{ V}) \sqrt{3}}$$

$$I_{line} = 114.27 \hbox{ A}$$

Deretter beregnes CT-sekundærstrømmens beløp:

$$I_{CT} = (114.27 \hbox{ A})\left(5 \over 200 \right)$$

$$I_{CT} = 2.857 \hbox{ A}$$

Fasevinkelen for hver linjestrøm bestemmes av fasefølgen. Med CBA-fasefølge ligger fase B 120 grader foran fase A, og fase C ligger ytterligere 120 grader foran fase B. Dermed:

\vskip 10pt

\vskip 10pt

Amperemeter ``C'' strøm = \underbar{$2.857$ A $\angle$ $220^o$}
