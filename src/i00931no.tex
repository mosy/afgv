Løs for $x$, $y$ og $z$ i dette systemet av samtidige ligninger:

$$x + 3y + 5z = 19$$

$$4x - y + 2z = 3$$

$$4x - y - z = 6$$

\vfil

\eject

Hvis vi trekker alle leddene i tredje ligning fra andre ligning, får vi:

$$4x - y + 2z - (4x - y - z) = 3 - (6)$$

$$4x - y + 2z - 4x + y + z = 3 - 6$$

$$3z = -3$$

$$z = -1$$

Setter vi denne verdien inn i de tre opprinnelige ligningene, står vi igjen med:

$$x + 3y - 5 = 19$$

$$4x - y - 2 = 3$$

$$4x - y + 1 = 6$$

\vskip 10pt

$$x + 3y = 24$$

$$4x - y = 5$$

\vskip 10pt

Nå kan vi løse for $x$ uttrykt ved $y$ (fra første ligning), og sette inn i den andre:

$$x + 3y = 24 \hskip 30pt x = 24 - 3y$$

$$4x - y = 5$$

$$4(24 - 3y) - y = 5$$

$$96 - 12y - y = 5$$

$$91 = 13y$$

$$y = 7$$

\filbreak

Når vi har $y$, setter vi verdien inn i $x = 24 - 3y$:

$$x = 24 - 3y$$

$$x = 24 - 3(7)$$

$$x = 24 - 21$$

$$x = 3$$

\vskip 10pt

Dermed er $x = 3$, $y = 7$ og $z = -1$.
