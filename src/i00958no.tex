Desibel er logaritmisk representasjon av effektforhold, der negative dB betyr demping og positive dB betyr forsterkning. 10 dB tilsvarer nøyaktig faktor 10, og 3 dB tilsvarer omtrent faktor 2.

\vskip 10pt

\begin{itemize}
\item{} +26 dB = effektforsterkning \underbar{\hskip 50pt}
\vskip 5pt
\item{} $-33$ dB = effektforsterkning \underbar{\hskip 50pt}
\vskip 5pt
\item{} +50 dB = effektforsterkning \underbar{\hskip 50pt}
\vskip 5pt
\item{} $-29$ dB = effektforsterkning \underbar{\hskip 50pt}
\vskip 5pt
\end{itemize}
