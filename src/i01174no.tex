Sannsynlighetsberegningen for en logisk OR-funksjon med to innganger følger denne formelen, der $A$ og $B$ er sannsynlighetsverdier mellom 0 og 1 (inkludert):

$$\includegraphics[width=15.5cm]{i01174x01.eps}$$

$$\hbox{Sannsynlighet for OR-funksjon med to innganger} = A + B - AB$$

\vskip 10pt

Utled en sannsynlighetsformel for en {\it tre-inngangs} logisk OR-funksjon:

$$\includegraphics[width=15.5cm]{i01174x02.eps}$$

\underbar{file i01174}
%(END_QUESTION)





%(BEGIN_ANSWER)

Vi kan bruke De Morgans teorem for å omskrive OR-porten med tre innganger til en AND-port med tre innganger og inverterte inn- og utganger, og deretter uttrykke sannsynlighetene tilsvarende:
 
$$\includegraphics[width=15.5cm]{i01174x03.eps}$$

$$\hbox{Sannsynlighet for OR-funksjon med tre innganger} = 1 - [(1 - A)(1 - B)(1 - C)]$$

$$\hbox{Sannsynlighet for OR-funksjon med tre innganger} = 1 - [(1 - B - A + AB)(1 - C)]$$

$$\hbox{Sannsynlighet for OR-funksjon med tre innganger} = 1 - [1 - C - B + BC - A + AC + AB - ABC]$$

$$\hbox{Sannsynlighet for OR-funksjon med tre innganger} = 1 - 1 + C + B - BC + A - AC - AB + ABC$$

$$\hbox{Sannsynlighet for OR-funksjon med tre innganger} = A + B + C - AB - BC - AC + ABC$$

%(END_ANSWER)
