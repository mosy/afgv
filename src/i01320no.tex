Innen maskineringsteknologi kan tiden som kreves for å ``brotsje'' et hull i en plate estimeres med følgende ligning:

$$T = {L \over C} + {L \over R_c}$$

\noindent
Hvor,

$T =$ Tid for å brotsje hull (minutter)

$L =$ Slaglengde (fot)

$C =$ Kuttehastighet (fot per minutt)

$R_c =$ Returhastighet (fot per minutt)

\vskip 10pt

Omform denne ligningen så mange ganger som nødvendig for å uttrykke den ved alle variablene.

Et første trinn vi må gjøre i alle disse omformingene, er å kombinere de to brøkene til én. Dette gjøres ved å finne fellesnevner:

$$T = {L \over C} + {L \over R_c}$$

$$T = {L R_c \over C R_c} + {C L \over C R_c}$$

$$T = {{L R_c + C L} \over C R_c}$$

$$T = {{L (R_c + C)} \over C R_c}$$

Herfra kan vi enkelt løse for $L$:

$$L = {{T C R_c} \over {R_c + C}} \hbox{\hskip 10pt . . . eller . . . \hskip 10pt} L = {T \over {{1 \over C} + {1 \over R_c}}} $$

\vskip 20pt

Vi kan løse for $C$ ved å starte med denne ligningen, så samle alle ledd som inneholder $C$ og faktorisere ut $C$:

$$T = {{L R_c + C L} \over C R_c}$$

$$C R_c T = L R_c + C L$$

$$C R_c T - CL = L R_c$$

$$C (R_c T - L) = L R_c$$

$$C = {{L R_c} \over {R_c T} - L} \hbox{\hskip 10pt . . . eller . . . \hskip 10pt} C = {L \over T - {L \over R_c}}$$

\vskip 20pt

Vi kan løse for $R_c$ ved å starte med denne ligningen, så samle alle ledd som inneholder $R_c$ og faktorisere ut $R_c$:

$$T = {{L R_c + C L} \over C R_c}$$

$$C R_c T = L R_c + C L$$

$$C R_c T - L R_c = C L$$

$$R_c (CT - L) = C L$$

$$R_c = {CL \over {CT - L}} \hbox{\hskip 10pt . . . eller . . . \hskip 10pt} R_c = {L \over T - {L \over C}}$$

\vskip 10pt

Ligning hentet fra side 3-139 i \underbar{Standard Handbook of Engineering Calculations}, redaktør: Tyler G. Hicks, P.E., ISBN 0-07-028734-1.
