I digitale elektroniske systemer basert på binærtallsystemet er antall mulige {\it tilstander} som kan representeres av systemet gitt ved følgende ligning:

$$n_s = 2^{n_b}$$

\noindent
Hvor,

$n_s =$ Antall mulige tilstander

$n_b =$ Antall binære ``biter''

\vskip 10pt

Hvordan kan du omforme denne ligningen for å løse for antall binære biter som trengs for å gi et bestemt antall tilstander?

\underbar{file i01322}
%(END_QUESTION)





%(BEGIN_ANSWER)

$$n_b = {\log n_s \over \log 2}$$

%(END_ANSWER)
