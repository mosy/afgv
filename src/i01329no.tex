I denne ligningen finnes en {\bf feil}. Finn feilen, og korriger den slik at uttrykkene på begge sider av likhetstegnet faktisk er like:

$${6 \over x + 2} - {{x - 4} \over {x + 2}} = {{6 - x - 4} \over {x + 2}}$$

\underbar{file i01329}
%(END_QUESTION)





%(BEGIN_ANSWER)

Korreksjon:

$${6 \over x + 2} - {{x - 4} \over {x + 2}} = {{6 - x + 4} \over {x + 2}}$$

%(END_ANSWER)





%(BEGIN_NOTES)

Husk å distribuere ``$-$''-tegnet! Dette er en {\it svært} vanlig feil blant algebrastudenter.
