$$m = K_p (\hbox{SP} - \hbox{PV}) + b$$

\noindent
Der,

$m$ = Manipulert variabel (utgang)

$K_p$ = Regulatorforsterkning

SP = Settpunkt

PV = Prosessvariabel

$b$ = Bias
