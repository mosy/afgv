I fysikk er en svært vanlig formel som relaterer posisjon ($x$), hastighet ($v$) og konstant akselerasjon ($a$) følgende:

$$x = x_o + v_ot + {1 \over 2}at^2$$

\noindent
Der,

$x =$ Sluttposisjon

$x_o =$ Startposisjon

$v_o =$ Starthastighet

$a =$ Akselerasjon

$t =$ Tid

\vskip 10pt

Deriver denne ligningen med hensyn på tid, og vis arbeidet ditt i hvert trinn. Forklar også betydningen av den deriverte ligningen (hva representerer ${dx \over dt}$ i fysikk?).

\underbar{file i01522}
%(END_QUESTION)





%(BEGIN_ANSWER)

Viser arbeidet trinn for trinn:

$$x = x_o + v_ot + {1 \over 2}at^2$$

$${d \over dt}x = {d \over dt}x_o + {d \over dt}v_ot + {d \over dt}{1 \over 2}at^2$$

$${d \over dt}x = 0 + v_o + at$$

$${dx \over dt} = v_o + at$$

\noindent
Der,

${dx \over dt}$ representerer hastighet.

%(END_ANSWER)

De fysiske variablene posisjon, hastighet og akselerasjon er utmerkede eksempler for å illustrere både derivasjon og integrasjon med hensyn på tid, fordi alle har personlig erfaring med dem.
