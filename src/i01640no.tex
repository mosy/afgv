{\bf Periode 1:}

\begin{itemize}
\item{}P er null, fordi avviket er uforandret
\item{}I er null, fordi avviket er null
\item{}D er null, fordi avviket er uforandret
\end{itemize}
\bigskip



{\bf Periode 2:}

\begin{itemize}
\item{}P øker, fordi avviket blir mer positivt
\item{}I øker, fordi avviket er positivt
\item{}D er positiv, fordi endringshastigheten i avviket er stabil og positiv
\end{itemize}
\bigskip



{\bf Periode 3:}

\begin{itemize}
\item{}P avtar, fordi avviket blir mer negativt
\item{}I øker, fordi avviket er positivt
\item{}D er negativ, fordi endringshastigheten i avviket er stabil og negativ
\end{itemize}
\bigskip



{\bf Periode 4:}

\begin{itemize}
\item{}P er null, fordi avviket er null og uforandret
\item{}I er positiv, fordi avviket er null og integralleddet tidligere har akkumulert en positiv verdi
\item{}D er null, fordi avviket er uforandret
\end{itemize}
\bigskip



{\bf Periode 5:}

\begin{itemize}
\item{}P avtar, fordi avviket blir mer negativt
\item{}I avtar, fordi avviket er negativt
\item{}D er negativ, fordi endringshastigheten i avviket er stabil og negativ
\end{itemize}
\bigskip



{\bf Periode 6:}

\begin{itemize}
\item{}P er negativ, fordi avviket er stabilt og negativt
\item{}I avtar, fordi avviket er negativt
\item{}D er null, fordi avviket er uforandret
\end{itemize}
